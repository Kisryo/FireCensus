## 2. 首页 `/`：3D 滚动叙事

**目的：** 评审在 60 秒内理解「问题是什么」和「为什么要用生态学的方法」。

**技术：** 一个 Spline 场景，用 Spline states 切换 5 个阶段；网页滚动位置（0–100%）驱动状态切换。每一段旁边浮出一张文字卡片。

| 段落 | 滚动区间 | Spline 状态 | 画面 | 文字卡片（英文要点） |
|---|---|---|---|---|
| ① 烟霾 | 0–20% | `S1_earth` | 地球慢转，东南亚上空一层半透明烟霾 | Every dry season, haze covers Southeast Asia. Satellites have watched these fires for 25 years. |
| ② 卫星 | 20–40% | `S2_satellites` | 5 颗卫星沿各自轨道出现，标上名字 | Five satellites, two generations: MODIS (2000–2027) and VIIRS (2012–). |
| ③ 漏看 | 40–60% | `S3_scan` | 光锥扫过婆罗洲；A 组火点被多颗照到、B 组被一颗照到、C 组闪一下就暗掉 | Each satellite misses fires the others see. And some fires are missed by all of them. |
| ④ 方法 | 60–80% | `S4_zoom` | 镜头拉近婆罗洲，火点旁浮现 (1,0,1) 这类捕获历史标签 | Ecologists count animals they can't fully see. We count fires the same way. |
| ⑤ 进入 | 80–100% | `S5_handoff` | 地球淡出，转场到分析页的 3D 地球 | `Explore the burning calendar →` 按钮 |

**交互细节**
- 首次进入显示加载画面（同时用来掩盖 FastAPI 冷启动），文字：`Waking up 5 satellites…`
- 右下角常驻「Skip story」按钮，直接跳到 `/explore`
- 首页背景偷偷调用一次后端 `/health`，把服务器叫醒

**手机版**
- 不载入 Spline 场景，改成 5 张静态截图 + 同样的文字卡片，避免卡顿和耗电

### 3.2 步骤流程

```
进入 /explore
  → [步骤 1] 选区域（三选一）
        a. 点案例卡片 → 镜头飞到预设范围
        b. 在 3D 地球上拖拽画框（或切 2D 地图画多边形）
        c. 输入经纬度范围（west, south, east, north）
  → [步骤 2] 选日期范围（默认 2000-11 至最新月份）
  → 按「Analyze」→ 调用 API → 显示加载进度
  → [步骤 3] 主视区切到「火灾天际线」
  → [步骤 4] 探索：开关、悬停、点击、比较
  → [步骤 5] 下载
```

### 3.3 视图 A：3D 地球（选区域用）

- 地球用 react-three-fiber 绘制，贴图沿用首页风格，让转场无缝
- 覆盖范围内的格子（0.25°）以发光点显示，亮度 = 该格子历年平均火点数
- 用户拖拽画出矩形，矩形贴着球面高亮
- 4 个案例以发光图钉标在地球上，点击即选中
- 切换 2D：变成平面地图（MapLibre），可以画多边形

### 3.4 视图 B：火灾天际线（主视图）

**画面：** 年 × 月的 3D 柱状网格。X 轴 = 月份（Jan–Dec），Z 轴 = 年份（2000–2025），柱高 = 协调后的火点数，颜色 = viridis 色阶（同一数值，高度和颜色双重编码）。

**数据来源开关（左侧面板 ③）**

| 选项 | 柱高显示 |
|---|---|
| Raw MODIS | 原始 MODIS 火点数（2012 年后明显偏低） |
| Raw VIIRS | 原始 VIIRS 火点数（2012 年才开始，前面是空的） |
| Raw combined | 两者直接相加（2012 年出现假跳升） |
| **FireCensus**（默认） | 协调后的 VIIRS 等效火点数 |

**「消失的火」动画：** 从 Raw MODIS 切到 FireCensus 时，柱子在 1.5 秒内长高；2000–2011 年的增量部分用半透明橙色标出，代表「找回来的火」。

**交互**
- 悬停柱子：浮出小卡片——年月、协调后火点数、90% 区间、原始 MODIS、原始 VIIRS、补回比例
- 点击柱子：右侧滑出该月的每日曲线（2D 折线 + 区间带）
- 拖拽旋转、滚轮缩放；「Reset view」按钮回到默认 45° 视角
- 「Anomaly mode」开关：颜色改成相对历年同月中位数的偏离（RdBu 发散色阶），柱高不变

**切换 2D：** 变回平面热力日历（年 × 月方格），配色、悬停、点击行为完全相同。这是无障碍和打印用的版本。

### 3.5 底部信息条

| 卡片 | 内容 | 对应官方要求 |
|---|---|---|
| This month vs history | 所选范围最新月份的火点数、历年同月中位数、百分位 | 与历史中位数比较 |
| Peak months & years | 火最多的 3 个月份、3 个年份 | 哪个月、哪一年火最多 |
| Unusual periods | 超过历史 90 百分位的概率 ≥ 0.8 的月份列表 | 异常状况 |
| Critical period | 典型火季的开始、高峰、结束周，以及今年的位置 | 关键时期 |
| Haze layer（仅泥炭地） | 估计燃烧量和 PM2.5 范围 | 影响力层 |

### 3.6 下载（左侧面板 ⑤）

| 文件 | 内容 |
|---|---|
| `hotspots_raw.csv` | 所选范围和日期的原始火点（三个传感器，含 sensor 栏位）；日期范围超过 1 年时提示改小 |
| `firecensus_monthly.csv` | 协调后的月度序列：年、月、火点数、区间下限、区间上限、原始 MODIS、原始 VIIRS |
| `calendar.png` | 当前视图截图（3D 或 2D） |
| `methods.txt` | 方法摘要和数据引用（FIRMS DOI） |

### 3.7 状态与错误

| 状态 | 显示 |
|---|---|
| 加载中 | 柱子从地面逐排升起的骨架动画 + 进度文字 |
| 后端冷启动 | `Our server is waking up (about 30 s)…` |
| 范围内没有火点 | `No fires detected in this area and period.` + 建议放大范围 |
| 范围超出覆盖区 | `This prototype covers SE Asia and Australia.` + 高亮覆盖区 |
| 只有 MODIS 的年份 | 柱子上方加小标记，悬停说明「estimated from MODIS only, wider interval」 |
| 只有两颗卫星的年份（2012–2017） | 悬停说明「lower bound」 |

## 5. 方法页 `/method`

由上到下：

1. **一张图讲方法**：数鱼 → 数火的类比动画（可复用首页 ③④ 的素材）
2. **捕获历史**：一个小表格示范 (1,1,1)、(1,0,1)、(0,0,0) 的意义
3. **侦测曲线图**：每颗卫星的 p(FRP, 像素面积)，叠上 Sofiev 2026 的侦测极限线（核心科学证据）
4. **验证结果**：E1–E8 一张表 + 2012 年假跳升消失前后对比图
5. **限制**：下限性质、封闭性假设、没有云量数据、配对误差
6. **数据与引用**：FIRMS 数据集 DOI、主要文献
7. **GitHub 链接**

# 第二版补充（2026-11-01）

## 9. 镜头预设：用一个 3D 场景解决「全站 3D」和「无障碍」的冲突

火灾天际线只有一个 3D 场景，配 4 个镜头预设按钮。**「切换 2D」不是另一个页面，而是镜头转到正上方**——同一份数据、同一套颜色，转场连贯，也只需要写一套代码。

| 按钮 | 镜头 | 用户看到 | 回答什么问题 |
|---|---|---|---|
| Isometric（默认） | 斜上 45° | 3D 柱状天际线，高度和颜色都代表火点数 | 整体印象，「消失的火」动画 |
| Front | 正面，沿年份方向看 | 12 根月份柱叠在一起 = 典型季节轮廓 | 一年中哪几个月最危险（关键期） |
| Side | 侧面，沿月份方向看 | 年份排开 = 年际趋势 | 哪一年火最多；2012 年假跳升有没有消失 |
| Top (2D) | 正上方，正交投影 | 平面年 × 月热力日历 | 无障碍、打印、截图；官方要求的「色阶日历」 |

**技术要点（react-three-fiber）**
- 镜头切换用补间动画（约 1 秒），Top 视角改用正交相机，避免透视变形
- Top 视角下柱子高度不再可见，所以颜色必须单独就能读出数值（viridis 已满足）
- 每个预设都有键盘快捷键：`1` `2` `3` `4`

## 10. 柱高的尺度

不同区域的火点数相差几百倍（文莱 vs 加里曼丹），所以：

- **柱高按所选区域自己的最大值归一化**，最高的柱子永远是固定高度
- 悬停卡片永远显示真实数字，不让人只靠高度判断
- 可选「对数尺度」开关，给科学家看小数值的变化
- 「消失的火」动画时，**尺度固定为 FireCensus 的最大值**，原始 MODIS 的柱子才会看起来真的「变高」，而不是被重新缩放

## 11. 三种用户的任务路径

每个官方要求都要在 **3 次点击内**完成。

**A. 紧急应变人员：「这个月正常吗？」**
1. 打开 `/explore`
2. 在地球上点自己的省份，或输入经纬度
3. 直接读底部「This month vs median」卡片 → 完成（2 次点击）

**B. 科学家：「过去 25 年的趋势是真的吗？」**
1. 选区域，日期保持默认
2. 按 `Side` 视角
3. 在 Raw combined 和 FireCensus 之间切换，看 2012 年的跳升有没有消失
4. 下载 `firecensus_monthly.csv` 自己分析（3 次点击）

**C. 土地管理者：「明年什么时候要准备？」**
1. 点案例卡片或画区域
2. 按 `Front` 视角，看季节轮廓
3. 读底部「Critical period」卡片：火季开始、高峰、结束周（2 次点击）

## 12. `/explore` 的状态流转

```
[idle]
  地球慢转，覆盖区格子发光，左侧只亮「1 Area」
    │ 选了区域
    ▼
[area_selected]
  区域高亮，「2 Dates」亮起，Analyze 按钮可用
    │ 按 Analyze
    ▼
[loading] ──(超过 5 秒)──► [cold_start] 显示「Our server is waking up…」
    │ 收到数据
    ▼
[results]
  镜头从地球飞到天际线（Isometric），底部信息条出现，「3 Data source」「4 Download」亮起
    │                          │                       │
    │ 点柱子                    │ 换数据来源              │ 改区域或日期
    ▼                          ▼                       ▼
[month_detail]            [results]（动画过渡）      [area_selected]
  右侧抽屉显示每日曲线
    │ 关闭
    ▼
[results]

错误分支：[no_fires] / [out_of_coverage] / [api_error]（附「Retry」按钮）
```

左侧控制面板按步骤逐步亮起（1 → 2 → 3 → 4），新用户不会迷路。

## 13. 首页到分析页的转场

1. 首页第 ⑤ 段：Spline 的镜头已经拉近婆罗洲
2. 用户按「Explore the burning calendar」
3. Spline 画面淡出 0.4 秒，同时 react-three-fiber 的地球淡入，**镜头位置和角度一致**，看起来是同一个地球
4. 预设区域自动选为「Borneo 2019」，直接进入 `[area_selected]`
5. 背景已经提前调用 `/health` 叫醒后端，按 Analyze 时通常不会遇到冷启动

关键：两个 3D 引擎的地球贴图、镜头视角（FOV）、背景颜色要完全一致，转场才会无缝。

## 15. 已知取舍

- 全站 3D 对旧笔电和手机吃力：手机版首页降级为静态图；分析页在手机上默认用 Top (2D) 视角
- 火灾天际线最多显示 26 年 × 12 月 = 312 根柱子，用 instanced mesh 一次绘制，性能没问题
- 「画区域」在 3D 球面上比较难做：比赛时间不够，就只保留案例卡片 + 经纬度输入，画框放到 2D 平面地图上做
