## Part 1 — Story_Scan / Story_Zoom（上一轮没收到的部分）

1. **光锥用各卫星自己的颜色**：Aqua #FFB74D、S-NPP #4FC3F7、NOAA-20 #64B5F6。
   - 锥体透明度约 8–10%。
   - 地面覆盖范围改成一圈清楚的轮廓线（约 2 单位宽、70% 不透明），只加极淡的填色。
   - 火点在光锥内要和光锥外一样清楚，不能被洗白。
2. **Story_Zoom 标签要能读**：
   - 字放大约 2 倍，粗体等宽字。
   - 每个标签加深色半透明圆角底（#0B0F1A，约 70%），用细引线连到它的火点；标签偏移到火点旁边，不要盖住火点。
   - 数字 1 用该卫星颜色、全亮；0 用灰色、40%。
3. **(0,0,0) 改成"幽灵火"**：
   - 不画实心火点，改成虚线空心圆（白色 50%），标签写 `(0,0,0) · estimated`。
   - 它代表三颗卫星都没看到、但模型估计存在的火，是我们方法的核心，视觉上要和真实观测到的火明显不同。
4. **Story_Zoom 的卫星**：移出画面，或缩小放在右上角。不能有卫星或太阳能板压在火点或标签区域。
5. **Story_Handoff**：补一张截图。

## Part 2 — 写实渲染图（render_sat.py 的材质要覆盖，不要沿用 NASA 原档材质）

问题：
- Terra 的太阳能板是一整片纯蓝色块。
- S-NPP 的太阳能板是米灰色。
- 三颗卫星的隔热膜都像哑光纸箱，不像金属箔。
- 灯光平，没有轮廓光。
- 地球露出的是欧洲，不是东南亚。

在 `render_sat.py` 里按物件或材质名替换：
1. **隔热膜（MLI）**：金色金属。Principled BSDF，base #C9A045，metallic 1.0，roughness 0.25–0.35，加皱褶法线贴图（用 Spline 那张或程序纹理 noise + voronoi），强度要足，渲染图里要明显看到皱褶反光。
2. **太阳能板**：深蓝紫电池片 #1A2350，加电池格线（brick 或 grid 纹理），细银色格线，roughness 0.15，带一点高光。正面要看得出一格一格。
3. **白色散热板**：#E8EAED，roughness 0.4。黑色件 #111316。
4. **灯光**：
   - 主光：强的侧向太阳光（sun，strength 4–5）。
   - 轮廓光：从背后打的冷白色光（area 或 sun，约主光的 40%）。
   - 补光：极弱。
   - 背光面要深但不能全黑，轮廓要清楚。
5. **地球**：旋转到卫星下方露出东南亚（苏门答腊、婆罗洲），和网站的故事一致。
6. **构图**：卫星占画面宽度约 55%，置中偏左；地球边缘在右下。
7. 加一点景深或泛光（bloom / glare），金属高光要有光晕。

重跑三张，覆盖原文件，另外各存一张 `_v1_old.jpg` 作对照。
